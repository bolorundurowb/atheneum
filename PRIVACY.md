# Atheneum Privacy Policy

Atheneum requires a number of permissions to function properly. The most important is the CAMERA permission which is needed to scan the bar codes behind most modern books. That eases the process of getting your books into your library quickly. The ISBN read from the bar codes are used to pull information about the book like the authors and publisher. That data is gotten from Google books and the data is is persisted on your atheneum account and not shared with any other third party.

## Permissions Required

### Camera

- Used to scan ISBN barcodes from physical books
- No images or video are stored or transmitted
- Camera access is only active during barcode scanning

### Internet Access

- Required to fetch book metadata from Google Books API
- Used for account synchronization
- Enables cloud backup of your library data

### Storage

- Stores your library data locally on device
- Caches book cover images for offline access
- All stored data is encrypted

## Data Collection & Usage

### What we collect

- Basic account information (email, encrypted password)
- Book metadata (ISBN, title, author, etc.)
- Library organization data (collections, reading status)

### How we use it

- To provide core app functionality
- To sync your library across devices
- To improve app features and performance

### Data Protection

- All data is encrypted in transit and at rest
- Personal data is never sold to third parties
- You can request deletion of your account and data at any time

## Third Party Services

### Google Books API

- Used to fetch book metadata
- Only ISBN numbers are shared with Google
- No personal data is transmitted

### Cloud Storage

- Encrypted backup of library data
- Hosted on secure cloud infrastructure
- Regular security audits and updates
